# Real-world Data Project (Retail Sales)

## Objective
Analyze a retail sales dataset and generate business insights.

## Dataset
Retail product sales dataset.

## Tasks Performed
- Data Analysis
- Statistical Summary
- Visualization
- Business Insight Generation

## Libraries Used
- Pandas
- Matplotlib

## Findings
- Laptop generated the highest sales.
- Sales distribution across products was visualized.
